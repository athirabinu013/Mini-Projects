# Calculator

A basic calculator project created using **HTML, CSS, and JavaScript**. The calculator is designed with a layout similar to a mobile calculator application.

## HTML Structure

The calculator is structured using HTML elements and containers to organize its different sections.

* A main **container** is created to represent the calculator body.
* **Division (`div`) containers** are used to separate the calculator into different rows and columns, similar to the layout of a mobile calculator app.
* **Buttons** are created for the calculator operations and numbers so that they can be clicked and interacted with.
* A separate **screen** is created to display the entered expression and the calculated answer.

## Current Features

* Mobile-calculator-inspired layout
* Separate rows and columns for calculator buttons
* Clickable number and operator buttons
* Display screen for expressions and answers
* Structured calculator body using containers
